# Project Governance

The DAM (Docker App Manager) project is an open-source project maintained by its founder and core maintainer, Ruthvik Upputuri. 

## Governance Model

This project uses a "Benevolent Dictator For Life" (BDFL) governance model. All final decisions regarding the roadmap, architecture, and inclusion of features are made by the core maintainer. Community feedback and consensus are heavily considered during the decision-making process.

## Key Roles and Responsibilities

- **Core Maintainer (Ruthvik Upputuri):** Responsible for reviewing and merging pull requests, publishing releases, managing security reports, and defining the overall direction of the project.
- **Contributors:** Community members who submit bug reports, feature requests, or pull requests. Contributors are expected to follow the `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.

## Access Continuity

To ensure the project can continue with minimal interruption if the core maintainer is incapacitated or unavailable:
1. The repository is hosted on GitHub, and a designated trusted secondary individual has been granted administrative access to the repository to manage issues and merges.
2. The domain `upputuri.in` and associated package registries are configured with emergency continuity access mechanisms, allowing the trusted secondary to transfer ownership or publish emergency updates if necessary.
